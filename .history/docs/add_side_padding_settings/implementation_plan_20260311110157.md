# 実装計画: 左右のサイド余白設定の追加と推奨サイズ計算の連携修正

## 概要
ユーザーがバナーグループ全体の左右余白（サイドパディング）をPCおよびスマホ別に自由に指定できるようにし、その設定値を管理画面の「推奨サイズ計算」に反映させます。

## 変更内容

### 1. メタボックスの拡張 (`includes/class-fb-meta-box.php`)
- コンテナ設定ボックスへ「PC側余白 (左右)」の入力項目を追加。
- スマホ側余白のデフォルト値を、0が指定可能なように調整（現在は0以下だと20にリセットされる仕様を修正）。
- 保存処理 (`save_data`) に新規項目の保存ロジックを追加。

### 2. 管理画面JSの修正 (`assets/js/admin.js`)
- `updatePreviewStyles` 関数を修正し、推奨サイズの計算式にサイドパディングを組み込む。
  - 計算式: `(コンテナ幅 - (サイド余白 × 2) - (カラム間余白 × (カラム数 - 1))) / カラム数`
- PC側余白・スマホ側余白の変更時にも、即座に計算結果が更新されるようにイベントリスナーを追加。

### 3. フロントエンド表示の修正 (`includes/class-fb-shortcode.php`)
- ショートコード実行時に、PC側余白をコンテナの `padding-left/right` としてCSSに適用。
- スマホ側余白の適用ロジックを最新の設定値に基づいて修正。

## バージョンアップ
- `flex-banner.php` のバージョンを `2.0.9` に更新。
