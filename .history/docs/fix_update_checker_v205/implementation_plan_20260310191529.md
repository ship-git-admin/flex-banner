# 実装計画: 更新チェックエラー修正 (v2.0.5)

## 現状の課題
- 更新チェック時に GitHub API から 404 エラーが返される。
- 原因は PUC がデフォルトで `master` ブランチを参照しようとしているが、リポジトリのデフォルトブランチが `main` であるため。

## 手順
1. **コードの修正 (`flex-banner.php`)**
   - `Version` を `2.0.5` に更新。
   - `$myUpdateChecker->setBranch('main');` を有効化し、`main` ブランチを参照するように設定。
   - GitHub の URL から末尾の `/` を削除。
2. **Git への反映**
   - 変更をコミットし、プッシュ。
3. **ユーザーへの案内**
   - ディレクトリ構造は既にフラット化済みであることを伝え、エディタでファイルを開き直すよう案内。

## リスク
- 特になし。ブランチ指定を正しく行うことで解決する見込み。
