# タスク: 3デバイス（PC/TB/SP）別のサイド余白設定の追加

## 概要
デバイスサイズに合わせて、より細かいレスポンシブなサイド余白（PC / タブレット / スマホ）を設定可能にし、推奨サイズ計算に反映させる。

## 目標
- [ ] `includes/class-fb-meta-box.php` に「タブレット側余白」項目を追加。
- [ ] `includes/class-fb-shortcode.php` で3つのブレイクポイント（PC: 1025px~, TB: 768~1024px, SP: ~767px）に応じたCSS出力。
- [ ] `assets/js/admin.js` の推奨サイズ計算（PC/SP）を最新の余白設定に完全同期。
- [ ] バージョンを `2.1.0` に上げる。
