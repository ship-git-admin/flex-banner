# 実装計画: ディレクトリ構造の見直し (v2.0.3)

## 現状の課題
- リポジトリのルートに `flex-banner/` というディレクトリがあり、その中にさらに `flex-banner/` というディレクトリがある二重構造になっている。
- 一般的な WordPress プラグインのリポジトリ構成（ルートにプラグインファイルを置く形式）に合わせる。

## 手順
1. **バージョン情報の更新**
   - `flex-banner/flex-banner/flex-banner.php` の `Version` を `2.0.3` に更新。
2. **ディレクトリの移動**
   - `flex-banner/flex-banner/` 内の全ファイルをリポジトリルート（`flex-banner/`）に移動。
   - 不要になった空の `flex-banner/` フォルダを削除。
3. **Git への反映**
   - `git add -A` で移動を検知させ、コミット。
4. **プッシュ**
   - GitHub へプッシュし、更新テストを可能にする。

## 注意点
- `SafeToAutoRun` を使用して、移動コマンドを一括実行する。
- 移動後、各種パス設定が壊れていないか確認する（プラグイン内では `plugin_dir_path(__FILE__)` を使用しているため問題ない見込み）。
