# 修正内容の確認 (Walkthrough) - フレキシブルバナープラグイン v2.0.0

今回のメジャーアップデートにより、フレキシブルバナープラグインはグリッド表示、スライダー、テキストオーバーレイ、スケジュールの各機能が統合された強力なバナー管理ツールになりました。

## 主な変更内容と確認方法

### 1. 管理画面 UI の強化
管理画面のバナー編集画面（Meta Box）で以下を確認してください。

- [ ] **表示モードの切り替え**: 「セクション」ヘッダーに「グリッド」と「スライダー」の切り替えボタンがあります。切り替えることで設定項目（列数/余白 または アニメーション設定）が動的に表示/非表示されます。
- [ ] **サイドバー設定**: 管理画面の右側に「コンテナ設定」が追加されました。PC最大幅を設定すると、各セクションの「推奨サイズ」計算もそれに連動して即座に更新されます。
- [ ] **アイテム複製**: セクション全体および個々のバナーを「複製」ボタンで瞬時にコピーできます。

### 2. リッチな表現
フロントエンド（ショートコード `[flex_banner id="XX"]`）で以下を確認してください。

- [ ] **スライダーモード**: 
    - 「スライド」および「フェード」のアニメーションをサポート。
    - 矢印ボタン、ドットナビゲーション、自動再生、インターバルの設定が反映されます。
    - モバイルでのスワイプ操作も可能です。
- [ ] **テキストオーバーレイ**: バナー画像の上にテキストを重ねることができます。見出し、本文、ボタンを個別に設定可能で、表示位置も全7パターンから選択できます。
- [ ] **スケジュール配信**: 
    - 開始/終了日時を設定すると、現在時刻に合わせて自動的にバナーが表示/非表示されます。
    - 管理画面上では、スケジュール設定されたアイテムに📅アイコンが表示されます。

### 3. コンテナとレスポンシブ
- [ ] **コンテナ幅**: 設定した最大幅がバナー全体の幅として適用されます。
- [ ] **SP余白**: 設定したSP側の余白が適用されます。

## 構成の確認

| 機能 | バージョン 1.0.0 | バージョン 2.0.0 (今回) | 備考 |
| :--- | :--- | :--- | :--- |
| **表示形式** | グリッドのみ | グリッド + スライダー | スライド/フェード対応 |
| **テキスト重畳** | 不可 | 可能 | 見出し、本文、ボタン |
| **配信制御** | 手動のみ | スケジュール予約可能 | 秒単位で設定可 |
| **運用効率** | - | セクション/アイテムの複製 | |
| **最大幅設定** | 944px 固定 | 自由に変更可能 | 推奨サイズ計算も連動 |

---
以上の機能により、今後のバナー運用において、コード改修を伴わない自由な更新が可能です。
