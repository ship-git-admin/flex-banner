# 実装計画: シンプルな操作ガイドの表示 (v2.3.1)

## 1. 目的
- 管理画面の「フレキシブルバナー」一覧ページにおいて、ユーザーがどのようにバナーを作成し、サイトに表示させるかの流れを迷わず理解できるようにします。

## 2. 修正方針
- **フックの利用**: WordPressの `admin_notices` フックを利用して、ページ最上部（タイトル下）に案内メッセージを表示します。
- **表示条件の限定**: `get_current_screen()` を使用して、当該投稿タイプのリストページ以外では表示されないようにします。
- **内容の簡略化**: 3つのステップにまとめ、視覚的に目立つアイコン（🐒, 💡）を使用します。

## 3. 修正対象ファイル
- `includes/class-fb-post-type.php`: 通知表示ロジックの追加。
- `flex-banner.php`: バージョン更新。

## 4. リリース
- `v2.3.1` として push。
