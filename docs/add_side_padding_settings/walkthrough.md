# 修正内容の確認 (Walkthrough) - v2.0.9

## 実施内容
バナーグループ全体の左右余白（サイドパディング）を自由に設定できる機能を追加し、それに合わせて管理画面の推奨サイズ計算ロジックを更新しました。

### 1. 左右余白の設定項目を追加
- **コンテナ設定**: 「PC側余白 (左右)」を新設し、「SP側余白 (左右)」も合わせて調整しました。
- **自由な指定**: これまではSP余白が0だと強制的に20pxにリセットされていましたが、0px（余白なし）も含めて自由に値を指定できるようになりました。

### 2. 推奨サイズ計算の精度向上
- **計算式の更新**: 管理画面の各セクションに表示される「推奨サイズ」の計算に、設定されたサイドパディングを反映させました。
  - PC推奨幅 = `(コンテナ最大幅 - (サイド余白 × 2) - (カラム間余白 × (カラム数 - 1))) / カラム数`
- **リアルタイム反映**: サイド余白の数値を変更すると、即座に推奨サイズの表示も更新されます。

### 3. フロントエンド表示の反映
- PC表示時およびスマホ表示時の両方で、設定されたサイドパディングが正しく適用されるようにCSS出力ロジックを修正しました。

### 4. 公開
- バージョン `2.0.9` として GitHub にプッシュ済みです。
