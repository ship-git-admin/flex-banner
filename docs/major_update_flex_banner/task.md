# タスクリスト (Task List) - フレキシブルバナープラグイン メジャーアップデート

フレキシブルバナープラグインをバージョン2.0へと大幅にアップグレードし、運用の手間を最小限に抑えつつ強力な機能を提供するためのタスクリストです。

## 完了済みのタスク

- [x] **プラグインメタデータの更新**
    - `flex-banner.php` のバージョンを 2.0.0 に更新。
    - 説明文に新機能（スライダー、テキストオーバーレイ、スケジュール、複製）を記載。

- [x] **管理画面 UI (Meta Box) の刷新**
    - セクション間の表示モード切り替え（グリッド / スライダー）を実装。
    - PC/SP 別の列数・余白設定を詳細化。
    - スライダー設定パネル（アニメーション、自動再生、インターバル、ナビゲーション）を追加。
    - サイドバーへの「コンテナ設定」（PC最大幅、SP側余白）の追加。
    - アイテムごとの「テキストオーバーレイ」設定（見出し、本文、ボタン、位置）をコラプシブルで実装。
    - アイテムごとの「表示スケジュール」設定（開始/終了日時）をコラプシブルで実装。

- [x] **管理画面 JavaScript (admin.js) の強化**
    - セクション（行）の複製機能を実装。
    - アイテム（バナー）の複製機能を実装。
    - コンテナ幅入力に連動した「推奨サイズ」の動的計算ロジックを実装。
    - 表示モード切り替えによる設定項目の表示/非表示制御。
    - テキストオーバーレイ設定状態を示すバッジの表示。

- [x] **フロントエンド表示 (Shortcode) のアップグレード**
    - スライダー表示モードの実装（フェード / スライド）。
    - 指定されたコンテナ幅・SP余白を適用する CSS 動的出力。
    - 現在時刻に基づいたバナーのスケジュールフィルタリング。
    - テキストオーバーレイ（7ポジション対応）のレンダリング。
    - 入れ子リンクの回避ロジック（ボタンURLがある場合に外側リンクを無効化）。

- [x] **アセットファイル (CSS/JS) の更新**
    - `admin.css`: 複製ボタン、モードトグル、コラプシブル、バッジ等の新UIスタイルを追加。
    - `style.css`: スライダー、アニメーション、テキストオーバーレイ、レスポンシブ等、フロントエンドの全スタイルを最適化。
    - `frontend.js`: バニラJSによる軽量なスライダー制御ロジックを新規追加。

- [x] **ポリッシュ & バグ修正**
    - CSS の空ルールセットの削除。
    - 保存処理におけるサニタイズ処理の追加。
    - スライダー1枚時のナビゲーション非表示制御。
    - スマホスワイプ対応。
