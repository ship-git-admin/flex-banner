# 実装計画 (Implementation Plan) - フレキシブルバナープラグイン

## 概要
柔軟なバナー管理プラグイン `Flex Banner` を全面的にアップデートし、運用コストを削減しながらリッチな表現（スライダー、テキストオーバーレイ、動的スケジュール）を可能にする実装計画です。

## フェーズ 1: UI / UX の刷新 (管理画面)
### 1.1 セクション（行）設定の拡張
- `grid` モードと `slider` モードの切り替えトグルの実装。
- `slider` モード時のアニメーションタイプ（フェード/スライド）、自動再生、インターバル、ナビゲーション（矢印/ドット）設定の追加。
- 管理画面サイドバーへの「コンテナ最大幅」および「SP側余白」の設定項目の追加。

### 1.2 アイテム（バナー）設定の拡張
- 「テキストオーバーレイ」設定の追加:
    - 見出し (Heading), 本文 (Body), ボタンテキスト (Button Text), ボタンURL (Button URL).
    - テキスト位置（7種類のプリセット）の選択肢。
- 「表示スケジュール」設定の追加:
    - 開始日時 (Start Date/Time), 終了日時 (End Date/Time) の入力を `datetime-local` で対応。

### 1.3 運用効率化機能の追加
- セクション全体の複製ボタンの追加。
- 各バナーアイテムの複製ボタンの追加。
- 設定項目の増加に伴う、アコーディオン（コラプシブル）形式でのグループ化。

## フェーズ 2: ロジックの実装（管理画面 & フロントエンド）
### 2.1 管理画面 JavaScript (admin.js)
- `globalContainerWidth` を PHP 側から `wp_localize_script` で受け取り、推奨サイズ算出の基準値として利用。
- コンテナ幅入力フィールドの値が変更された際、全セクションの推奨サイズガイドをリアルタイムに再計算。
- 複製処理時に、各入力要素の `name` 属性（インデックス番号/ID）を衝突しないよう動的に置換。

### 2.2 フロントエンド表示 (Shortcode)
- スケジュール判定ロジック: 現在時刻と比較し、表示対象外のバナーをレンダリングから除外。
- コンテナ設定の反映: 保存されたコンテナ幅を `fb-container` の `max-width` として CSS 動的に埋め込み。
- スライダー表示モードのレンダリング。

## フェーズ 3: アセットの最適化
### 3.1 CSS (Admin/Frontend)
- `admin.css`: 階層構造が分かりやすいようカード形式のデザイン、モード切り替えトグル、バッジ（スケジュール/テキスト設定済みフラグ）等のビジュアルコンポーネントを定義。
- `style.css`: フロントエンドのグリッドレイアウトおよびスライダー要素のスタイリング。レスポンシブデザインの網羅。

### 3.2 JavaScript (Frontend)
- ライブラリ（jQuery 等）に依存しない、純粋な JavaScript (Vanilla JS) による軽量なスライダークラスを実装。
- フェード/スライドのトランジションアニメーション。
- 矢印、ドット、タッチスワイプ（モバイル）の制御。
