# フレキシブルバナープラグイン - ウォークスルー

## インストールとセットアップ

1.  **ライブラリのインストール**:
    - このプラグインには `plugin-update-checker` ライブラリが必要です。
    - 以下のURLからダウンロードしてください: https://github.com/YahnisElsts/plugin-update-checker
    - ZIPを解凍し、中身を `lib/plugin-update-checker/` に配置します。
    - `plugin-update-checker.php` が `lib/plugin-update-checker/plugin-update-checker.php` に配置されていることを確認してください。
    - `flex-banner.php` を開き、`Puc_v4_Factory::buildUpdateChecker` 内のリポジトリURLを実際のGitHubリポジトリURLに更新してください。

2.  **プラグインの有効化**:
    - WordPress管理画面 > プラグインに移動します。
    - 「フレキシブルバナーグループ」を有効化します。

## 使い方

### 1. バナーグループの作成
1.  ダッシュボードの新しい **フレキシブルバナー** メニューに移動します。
2.  **新規追加** をクリックします。
3.  タイトルを入力します（例: 「トップページ メインバナー」）。
4.  コンテンツエディタは空のままで構いません。下の **バナーレイアウト** メタボックスを使用します。

### 2. レイアウトの設定
1.  **セクションを追加**: 「セクションを追加」ボタンをクリックして新しい行を作成します。
2.  **カラム設定**:
    - **PC カラム数**: 1〜4カラムを選択します。
    - **SP カラム数**: 1または2カラムを選択します。
    - *ヒント*: 選択したカラム数に応じて「推奨サイズ」ガイドが更新されます。
3.  **画像の追加**:
    - セクション内の **画像を追加** をクリックします。
    - **PC用画像**: メディアライブラリから画像を選択します。
    - **SP用画像** (オプション): モバイル専用の画像を選択します。選択しない場合はPC用画像が使用されます。
    - **リンクURL** (オプション): バナーのリンク先URLを入力します。
4.  **並べ替え**:
    - **☰** ハンドルをドラッグして行を並べ替えます。
    - 行内の **移動アイコン** をドラッグして画像を並べ替えます。
5.  **保存**: 「公開」または「更新」をクリックします。

### 3. サイトへの表示
1.  ショートコード（例: `[flex_banner id="123"]`）をコピーします。
    - 投稿IDは編集画面のURL（例: `post.php?post=123...`）で確認できます。
2.  このショートコードを固定ページや投稿の本文に貼り付けます。
3.  設定したレイアウトでバナーが表示されます。

## テクニカル詳細

- **レスポンシブ**: ブレイクポイントは **767px** に設定されています。
- **画像**: アートディレクション（PC/SPのソース切り替え）のために `<picture>` タグを使用しています。
    - パフォーマンス向上のため、`loading="lazy"` と `decoding="async"` が有効になっています。
    - CLS（レイアウトシフト）防止のため、`width` と `height` 属性が自動的に付与されます。
- **CSS**: 
    - コンテンツ最大幅: **944px**。
    - ギャップ: **12px** (PC), **10px** (SP)。
    - クラス名はBEM手法（例: `.fb-row`, `.fb-image`）に従っています。

## トラブルシューティング
- **画像が表示されない**: PC用画像が選択されているか確認してください。
- **レイアウトが崩れる**: テーマのCSSが `.fb-container` や `.fb-row` と競合していないか確認してください。
- **アップデートチェッカーのエラー**: `plugin-update-checker.php` へのパスとリポジトリURLが正しいか確認してください。
