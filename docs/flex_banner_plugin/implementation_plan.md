# 実装計画 - フレキシブルバナープラグイン

## ユーザー要件
- ショートコード経由でフレキシブルなバナーを表示するWordPressプラグインを作成する。
- **管理画面**: 「フレキシブルコンテンツ」のようなUI（行の追加、並べ替え、レイアウト変更）。
- **複数グループ**: IDによる管理（カスタム投稿タイプを使用）。
- **レスポンシブ**: PC (1-4カラム), SP (1-2カラム)。ブレイクポイント: 767px。
- **画像**: `<picture>` タグを使用したPC/SPの切り替え。遅延読み込み（Lazy loading）。
- **サイズ/余白**: コンテンツ幅 944px、狭いギャップ。
- **アップデートチェッカー**: `plugin-update-checker` の統合（ダミーURL）。
- **構造**: BEM CSS、管理画面UIにはフレームワークに依存しない（jQuery/WP標準）。

## アーキテクチャ

### 1. プラグイン構造
```
flex-banner/
├── flex-banner.php           # メインプラグインファイル（定義、初期化）
├── README.md
├── includes/
│   ├── class-fb-cpt.php      # カスタム投稿タイプの登録（'flex_banner_group'）
│   ├── class-fb-admin.php    # 管理画面UI（メタボックス、保存ロジック）
│   └── class-fb-display.php  # フロントエンドレンダリング（ショートコード）
├── assets/
│   ├── css/
│   │   ├── admin.css         # 管理画面用スタイル
│   │   └── style.css         # フロントエンド用スタイル (BEM)
│   └── js/
│       └── admin.js          # 管理画面用ドラッグ＆ドロップ、画像アップローダー
└── lib/
    └── plugin-update-checker/ # 外部ライブラリ
```

### 2. データ保存
- **投稿タイプ**: `flex_banner_group`
- **メタデータ**: `_flex_banner_data` (行の配列をシリアル化して保存)
    - 構造:
      ```json
      [
        {
          "type": "row",
          "columns_pc": 3,
          "columns_sp": 1,
          "items": [
            { "img_pc": 123, "img_sp": 124, "url": "https://..." },
            { "img_pc": 125, "img_sp": 126, "url": "https://..." }
          ]
        }
      ]
      ```

### 3. 管理画面インターフェース
- `add_meta_box` を使用してエディタを作成。
- **JavaScript (jQuery)**:
    - 行の並べ替えに `Sortable` を使用。
    - 画像選択に `wp.media` を使用。
    - 選択に基づき、行やカラムを動的に追加/削除。
    - カラム数とギャップに基づき「推奨画像サイズ」を算出。

### 4. フロントエンドレンダリング
- ショートコード: `[flex_banner id="123"]`
- ロジック:
    - IDから投稿メタ `_flex_banner_data` を取得。
    - 行と項目をループで処理。
    - `<picture>` タグを使用したHTMLを生成。
    - カラム数に基づいたCSSクラス（例: `.fb-row--pc-3`）を適用。

### 5. アップデートチェッカー
- ライブラリコード（またはスタブ）を含める。
- ダミーURLを使用して `flex-banner.php` で初期化コードを追加。

## ステップ別の実装手順

1.  **セットアップ**: ファイルとディレクトリの作成。
2.  **CPT**: `flex_banner_group` の登録。
3.  **管理画面UI (HTML/CSS)**: メタボックスの構造とスタイルの作成。
4.  **管理画面UI (JS)**: ドラッグ＆ドロップ、カラム変更ロジック、メディアアップローダーの統合。
5.  **保存ロジック**: 複雑な配列データの保存処理。
6.  **フロントエンド**: ショートコードレンダリングとレスポンシブCSSの実装。
7.  **微調整**: 画像サイズガイドの追加、CSSの調整（ギャップ、レスポンシブ性）。
