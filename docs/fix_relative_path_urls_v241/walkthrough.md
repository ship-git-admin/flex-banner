# 修正内容の確認 (v2.4.1)

## 修正のポイント
### 1. 相対パス時の正しいルーティング
バナー画像やキャプションボタンのリンク先として設定欄にスラッグ（例: `company` や `/company`）を入力した際、これまではブラウザのドメイン直下（`http://shipinc0000.xsrv.jp/company`）扱いとなる場合がありました。

今回の修正により、WordPressが現在ある階層情報を取得する `home_url()` と正しく結合するようになりました。開発環境のようなサブディレクトリ環境（`/dev/001_development/`）であっても、自動的に
`http://shipinc0000.xsrv.jp/dev/001_development/company` 
へと変換・補完されます。

一方、外部リンク（`https://...`）やアンカー（`#...`）については、意図通りそのまま出力されます。
