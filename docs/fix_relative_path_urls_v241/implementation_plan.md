# 実装計画: URL正規化メソッドの実装 (v2.4.1)

## 1. 目的
- プラグインに入力されたリンク先が `about-us` や `/contact` のような相対パスである場合、ブラウザのドメイン直下ではなく、そのWordPressがインストールされているホームURL（サブディレクトリ環境対応）を起点とした正しいリンクを生成させる。

## 2. 実装手法
1. **専用ヘルパー関数の作成**: ショートコードクラス内に `format_banner_url()` という関数を作成します。
2. **プレフィックスの判定**: 
   - `http://`, `https://`, `#`, `?`, `mailto:`, `tel:` などから始まるパスはそのまま保持します。
   - それ以外のパス（相対パス）の場合は、先頭付近の余分なスラッシュを削除し、WordPressコア関数である `home_url('/')` の末尾に結合させます。
3. **描画への適用**: `url` と `caption_btn_url` の変数へ反映させます。

## 3. これによるメリット
- 環境（開発用のサブディレクトリ環境、本番環境の直下・サブディレクトリなど）に依存せず、常に適切な階層へユーザーを誘導できます。
