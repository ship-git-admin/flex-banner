# タスク: 管理画面の編集権限復旧およびバージョン 2.2.3 のリリース

## 概要
前回の変更（v2.2.2）で導入されたカスタム権限設定（`edit_flex_banner` 等）が、管理者に適切に割り当てられていなかったため、管理画面の投稿一覧で「編集」リンク等が表示されなくなっていました。これを修正し、バージョン 2.2.3 を公開します。

## ステップ
1. [x] `includes/class-fb-post-type.php` の権限設定を修正
   - `edit_post`, `read_post`, `delete_post` を `$manage_cap` (`manage_options`) に再割り当て
2. [x] バージョン番号の更新
   - `flex-banner.php` を 2.2.3 に変更
   - 管理画面・フロントエンド用アセットのバージョンを 2.2.3 に同期
3. [x] 変更の保存とコミット
4. [x] リポジトリへのプッシュ
5. [x] `v2.2.3` タグの作成とプッシュ
