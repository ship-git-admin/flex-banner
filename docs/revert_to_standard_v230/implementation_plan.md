# 実装計画: 権限機能の撤去と標準化 (v2.3.0)

## 1. 背景
- v2.2.x 系統で実施してきた独自の権限制限およびマッピングが、特定の環境（既存のメニュー管理プラグイン等）と激しく干渉し、サイドバーメニューの消失や編集不能といった問題を引き起こしました。
- ユーザーの要望に基づき、プラグイン側での権限制限ロジックを破棄し、最も安定した標準構成に戻します。

## 2. 修正方針
- **権限の標準化**: `register_post_type` の引数から `capabilities` などのカスタム記述を削除し、`capability_type => post` のみに絞ります。
- **プラグインの役割限定**: プラグインはバナー管理機能の提供に専念し、アクセス制御はWordPress本体の権限システムおよび運用環境に委ねます。
- **確実な復旧**: 他のプラグイン（WP Sheet Editor等）によるメニューの改変がある環境でも、標準のCSTとして認識されやすい構成にします。

## 3. 修正箇所
- `includes/class-fb-post-type.php`: マッピング解除と初期化優先順位のリセット。
- `flex-banner.php`: バージョン 2.3.0 へのメジャー（マイナー）アップデート。

## 4. リリース
- `v2.3.0` として push。
