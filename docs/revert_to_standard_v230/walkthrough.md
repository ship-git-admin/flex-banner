# 修正内容の確認 (v2.3.0)

## 修正のポイント
### 1. 権限機能の全削除
`register_post_type` において以下の変更を行い、プラグイン独自の権限ロジックを撤廃しました。
- `capabilities` 配列の削除。
- `capability_type` を `post` に固定。
- `map_meta_cap` の設定を（デフォルトに依存させる形で）整理。

これにより、この投稿タイプ（フレキシブルバナー）は標準の「投稿（post）」と同じ権限で動作するようになります。管理画面に表示されない問題は、これで解消されるはずです。

### 2. 今後の権限管理について
特定のロール（管理者のみ等）にアクセスを制限したい場合は、環境に導入されている `User Role Editor` や `Admin Menu Editor` などのプラグインを使用して、`フレキシブルバナー` に対する権限を設定してください。
