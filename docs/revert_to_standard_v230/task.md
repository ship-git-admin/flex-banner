# タスク: 権限管理機能の削除と標準構成への回帰 (v2.3.0)

## 概要
サイドバーが表示されない等の権限関連のトラブルを根本的に解決するため、プラグイン側での独自権限管理機能を全て削除しました。今後はWordPress標準の投稿権限（`capability_type => post`）を使用し、具体的な閲覧・編集制限は環境側（User Role Editor 等のプラグイン）で設定する運用に変更します。

## ステップ
1. [x] `includes/class-fb-post-type.php` の修正
   - `capabilities` 配列による独自マッピングを全て削除。
   - `capability_type` を `post` に設定し、標準の挙動（投稿と同じ権限体系）に統合。
   - `init` の優先順位をデフォルト（10）に戻し、`menu_position` も削除。
2. [x] バージョン番号の更新
   - 機能の大幅な変更（削除）に伴い、バージョンを 2.3.0 に更新。
   - アセットのバージョンも 2.3.0 に同期。
3. [x] Git へのプッシュとタグ `v2.3.0` の発行。
