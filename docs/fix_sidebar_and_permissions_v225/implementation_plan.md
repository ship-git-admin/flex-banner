# 実装計画: サイドバーメニューの復旧と干渉回避 (v2.2.5)

## 1. 現状の課題
- 前回の修正 (v2.2.4) でもメニューがサイドバーに表示されない状態が続いています。
- 提供されたHTML構造から、`Admin Menu Editor` などのメニュー管理プラグインや、`WP Sheet Editor` などによるメニューの改変が確認されました。
- これらにより、標準的なタイミングでのCST登録が意図せず隠されたり、上書きされたりしている可能性があります。

## 2. 修正方針
- **フックの優先順位調整**: `init` フックの優先順位をデフォルトの10から `20` に下げ（実行を遅らせ）ます。これにより、他のプラグインによる定義が行われた後で確実に上書き・登録を完了させます。
- **表示位置の明示**: `menu_position` を `5` に指定し、管理画面上部（ダッシュボードのすぐ下）に強制的に配置を試みます。
- **権限の再構成**: `capabilities` 配列を最小限かつ主要なものに絞り込み、`manage_options` による判定を確実なものにします。

## 3. リリース
- バージョン 2.2.5 としてタグ発行およびプッシュ。
